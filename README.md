## Duck Hunt / Word Hunt
 with a small variation. Instead of shooting a duck, we want a player to shoot a letter instead. 
 
# Here is rough idea about this game. 
- There's a set of words related to Javascript. Words are grouped by level of difficulties. For example Easy words are 5-6 characters long, Medium maximum 8 characters, and Hard is 10 characters
- One round contains 10 words to complete, with timer of 60 second to complete.
- when a player press start he will be given a word with one or two missing characters, and timer is on. Then some letters will start flying across the screen 
- a player will use arrow keys to move the crosshair to track the letter, 
- the user is tasked with an objective to shoot the "flying" letters or words to complete the missing letters of the word from a predefined set of word list.

- The Objective follows the set of rules of the well-known game, "Duck Hunt" from NES.
- We are making a variant of this game using letters and words.  
    - We will be using our keyboard's arrow keys as the input command keys for movement.  No mouse required.
    - Spacebar will be used to "shoot" the target.
    - We will be using the letter key "B" to pause the game.
    
    This introduces a new feature, "Pause Screen"
        When this prompt opens in the center of the screen. 
        To navigate through the menu.  
            - Arrow Up and Arrow Down key to navigate.
            - Spacebar to execute confirmation.
        
On top of the screen, you can track your status.
    There will be timer, lives, score, and possibly ammo to track how many chances there will be.

For now, we are treating the letter and words like a duck from duck hunt til we figure out how to handle this object.

This is the general overview scope on the user side experience.
